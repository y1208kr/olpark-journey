# 올팍 두 여정 진단

방문객이 겪는 여정과 올림픽공원이 제공하는 운영 여정을 나란히 놓고, 두 여정이 맞지 않는 시간과 접점을 공공데이터로 찾는 정적 웹 서비스입니다. 2026년도 한국체육산업개발(주) 공공데이터 활용 경진대회 출품작입니다.

## 화면
- 방문 계획 도우미: 요일, 방문 목적, 도착 시각을 고르면 시간대별 입차와 출차, 만차 기록 비율, 맞춤 안내를 보여 줍니다.
- 이중 여정 지도: 7단계마다 방문객 행동, 방문객 질문 수, 공원 운영 활동, 데이터 신호를 나란히 놓고 불일치 접점을 표시합니다.
- 몰랐던 접점: 질문이나 행동 데이터는 있는데 운영 여정에 대응 단계가 없는 접점을 정리합니다.
- 분석 결과: FAQ 텍스트 분석(TF-IDF, 동시출현 네트워크), 출차 패턴 k-means, 늦은 출차 회귀 분석 결과를 그림과 함께 보여 줍니다.
- 데이터와 방법: 진단 절차, 출처, 한계를 공개합니다.

## 데이터
모두 공공데이터포털(data.go.kr)에 개방된 한국체육산업개발주식회사 파일데이터입니다.

| 데이터 | 번호 | 사용 범위 |
|---|---|---|
| 올림픽공원 입출차 정보 | 15138735 | 2024.7.1~7.31, 215,528건 |
| 주차장 혼잡도 정보 | 15164156 | 2025.2~2026.8 중 92일, 699건 |
| 월별주차현황 | 15131671 | 2023.1~2025.12 |
| 자주 묻는 질문정보 | 15089962 | 49건(올림픽공원 37건 사용) |
| 올림픽공원 핫뉴스 정보 | 15090715 | 126건 |
| 영문 공연정보 | 15149169 | 2024년 7월 공연일 |

- `data/aggregates.json`: 원자료를 시간대, 요일 유형, 체류시간, 일자별로 집계한 값
- `data/faq_coded.csv`: FAQ 49건에 여정 단계를 붙인 분류표

## 분석 코드
`analysis/` 폴더의 파이썬 코드로 페이지의 분석 수치와 그림을 다시 만들 수 있습니다. 실행 방법과 방법 선택 이유는 `analysis/README.md`에 있습니다.

```
pip install -r analysis/requirements.txt
python analysis/run_all.py
```

## 한계
입출차 데이터는 2024년 7월 한 달치이고 차량 기준이라 도보와 대중교통 방문객은 포함되지 않습니다. FAQ는 기관이 정리한 질문이므로 원시 민원 전체가 아닙니다. 공연일과 늦은 출차의 관계는 상관이며, 회귀 분석에서 공연일 계수는 유의하지 않았습니다(p = .122, n = 31).
